Verify your download

Compare the SHA-256 of the file you downloaded with the value above. The same values for every file are in SHA256SUMS.txt. If they differ, do not install it.

macOS: shasum -a 256 ~/Downloads/<file>
Windows: certutil -hashfile <file> SHA256

SPRINT is not code-signed yet, so your computer shows a warning the first time. See Install help.
