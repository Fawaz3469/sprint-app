Install help

SPRINT is not code-signed yet, so your computer shows a warning the first time. It is safe to continue.

macOS

  1. Open the .dmg and drag SPRINT into Applications.
  2. Right-click (or Control-click) SPRINT and choose Open, then Open again.
  3. If you only see "Move to Bin": open System Settings, Privacy & Security and click Open Anyway.

Windows

  1. Run the installer.
  2. On "Windows protected your PC", click More info.
  3. Click Run anyway.
